- 敏感配置（API Key、密钥、token）只从 .env 读取，禁止硬编码、禁止打印到日志
- .env.example 必须提供所有变量模板，包含注释说明用途
- 数据库中敏感信息（密码、token、个人隐私）禁止明文存储，必须加密或哈希
- 用户输入必须校验后再使用，禁止直接拼接到 SQL、命令或渲染到页面
- 接口必须挂鉴权中间件，禁止遗漏受保护路由的权限校验
- 日志禁止打印敏感数据（密码、token、密钥、完整请求体）
- 禁止在前端或任何客户端暴露内部微服务间通信地址、API Key 或密钥
- 涉及实时通信（WebSocket 信令、WebRTC 信令交换通道）必须走加密协议（WSS / TURNS / HTTPS）
- AI 服务响应禁止泄露原始 prompt、系统指令、外部 API Key 或内部工具链信息

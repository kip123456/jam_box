- 路由按资源或功能分模块，禁止所有路由堆在单个文件
- 接口必须版本化，路径格式 /api/v1/资源/动作，如 /api/v1/rooms
- 接口返回值必须统一格式：`{ code: number, msg: string, data: T }`，禁止返回裸数据或裸错误消息
- 错误必须统一处理：业务代码只抛错误对象，由全局错误中间件映射到 code + msg，禁止在业务代码里拼装错误响应
- 禁止 SQL 拼接，必须用参数化查询或 ORM 提供的安全接口
- 缓存必须设置过期时间，禁止永久缓存；缓存 key 必须有命名规范，避免不同业务互相覆盖
- 所有外部调用（数据库、缓存、第三方 API）必须有超时，禁止无限等待
